Before you begin

Made for Mac and Windows.

Platforms, payloads and limitations
You bringWhat to know
An Apple Silicon MacmacOS 14 or newer. Metal plus the MLX engine (Metal v3); no Metal v4 overlay.
Or an Intel MacmacOS 14 or newer. CPU only; no Metal or MLX engine.
Or a Windows PCWindows 10/11 x64 with UCRT. CPU and required runtime DLLs; no MLX engine.
Models and disk spaceModels are pulled separately into an Ollama models folder. Check each model's license and memory needs.
4D 20+ for integrationInstall the ollama component. Direct HTTP use does not require 4D.

No desktop app, Linux or Windows ARM builds, or CUDA/ROCm/Vulkan payloads are included.

Keep local inference local.

Set OLLAMA_HOST=127.0.0.1:8080 (the component defaults to host 127.0.0.1). Do not expose an unauthenticated server to an untrusted network.

From download to conversation

Your first local request.

This path uses the native build directly, without 4D. If the component is already managing a server on port 8080, use that server instead of starting another one.

01

Start the engine on localhost

Shell / macOS
{% highlight shell %} OLLAMA_HOST=127.0.0.1:8080 macOS/arm64/ollama serve {% endhighlight %}

In PowerShell: $env:OLLAMA_HOST='127.0.0.1:8080'; .\Windows\ollama.exe serve. Leave it running and check it from another terminal:

{% highlight shell %} curl --fail http://127.0.0.1:8080/api/version {% endhighlight %}
02

Pull a model

Shell / macOS
{% highlight shell %} OLLAMA_HOST=127.0.0.1:8080 macOS/arm64/ollama pull llama3.2:1b {% endhighlight %}
03

Start a conversation

Shell / macOS
{% highlight shell %} curl -X POST http://127.0.0.1:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "llama3.2:1b", "messages": [{"role": "user", "content": "Hello!"}], "max_tokens": 100, "stream": false }' {% endhighlight %}

Ollama loads a model on its first request, so the first reply may take longer.

Connect with tools you know

A familiar API. A local address.

Point AI Kit's OpenAI client at your running server.

{% highlight 4d %} var $AIClient : cs.AIKit.OpenAI $AIClient:=cs.AIKit.OpenAI.new() $AIClient.baseURL:="http://127.0.0.1:8080/v1" {% endhighlight %}
